DOCS FOLDER
---

This folder is for referring to all reading and paper documents used in the development of this project.

Currently, many items are listed in .md files. The REFERENCES.md is a collection of useful papers and their plain-text or bib-tex references for easy construction of a .tex document and resulting .pdf.

SPRINT1.md is a reference for the requirements and development work done for EC601 Sprint 1. The formatting is less important than the recorded content, but it should be cleaned up at some point.

TEAM.md is a record of how to document and communicate issues, work being done, problems, etc. It is a "how-to" of communication, not communication itself.
